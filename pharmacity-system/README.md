# Pharmacity System

Thu muc nay gom:

- `backend`: Laravel API
- `frontend`: Vue/Vite giao dien

Huong dan nhanh:

1. Backend
   - sao chep `backend/.env.example` thanh `.env`
   - chay `composer install`
   - chay `php artisan key:generate`
   - chay `php artisan migrate`

2. Frontend
   - sao chep `frontend/.env.example` thanh `.env`
   - chay `npm install`
   - chay `npm run dev`
